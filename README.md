сервер + вбудований клієнт. один деплой на railway — і грають.

─────────────────────────
НОВЕ У V3
─────────────────────────
• анімації карт: поява на столі, ляск захисту, добір у руку,
  зліт у відбій.
• поля добору і відбою + механічний годинник матчу.
• чат у лобі столу (до старту гри).
• менюв: додано «досягнення»; підекрани — кнопка «назад».
• очки спрощено: перемога +25, середина +5, останній −15,
  нічия нагорі +10, швидка партія (<5 хв) бонус +10.
  нижче нуля не падаєш. старий рейтинг мігрує (−1000, підлога 0).
• звання унісекс, без дивізій:
  новачок→спритник→хитрюга→майстер→дур-маф→маф-легенда ✎
  показуються в [] біля ніка після 10 ігор.
• досягнення (унікальні звання, іконки потім):
  блискавка · ніп-дипломат · суха лапка · п'ятикутник · хвиля няву
• котяча іконка на всіх картах киць (жаби вже були).

─────────────────────────
БУЛО У V2
─────────────────────────
• столи 2–5 гравців: хост створює, друзі заходять за кодом,
  хост тисне «почати». вибування по колу, місця 1..N.
• менюв: посібник з правил (стос секцій), всесвітні рекорди,
  кредитси (autor — amadeus_koma & gregosmogony, донателло),
  «вийти з матчу» — з'являється лише під час матчу.
• лагідний таймер: розрив з'єднання — 10 хв на повернення.
  той, хто чекає, може вийти без покарання: технічну поразку
  отримує зниклий, не чекач.
• тиша — лагідні автодії: няв обирається сам (90с), захисник
  бере (180с), підкидачі пасують (90с); викидання лише для
  атакера, що мовчить 3 хв.
• очки й звання овервоч-стилем: 7 тірів × 5 дивізій (V→I),
  попарне ело за місця, бусти на здобуті очки:
    швидкість: <4 хв ×1.5, <8 хв ×1.2
    серія 3+ перемог ×1.25
    новачок (перші 10 ігор) ×1.5
  тіри ✎: кошеня→кицька→киця→котяра→вусач→дур-маф→маф-легенда
• анти-киці — жаби: жаб'ячі іконки на картах анти-мастей
  і на ніпах зелений/фіолетовий/синій.
• точний лічильник карт суперників (цифрою на чипі).

ЗАПУСК І ТЕСТИ
─────────────────────────
npm install && npm start        → http://localhost:3000
node sim_core.js                → 2000 партій ядра на 2–5 гравців
PORT=3111 npm start & npm test  → живі сокет-тести (3 гравці + баг втечі)

─────────────────────────
ДЕПЛОЙ НА RAILWAY
─────────────────────────
1. цю теку → github-репозиторій
2. railway.app → New Project → Deploy from GitHub repo
3. Settings → Networking → Generate Domain
4. ОБОВ'ЯЗКОВО: Settings → Volumes → mount path /app/data
   (інакше рекорди зникнуть при редеплої)
порт railway підставить сам через PORT.

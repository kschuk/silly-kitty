ЗАПУСК І ТЕСТИ
─────────────────────────
npm install && npm start        → http://localhost:3000
node sim_core.js                → 200 партій ядра на 2–5 гравців
node test_client.js               → клієнт: помилки скрипта й мертві кнопки
node run_tests.js 3199 test_integration.js test_v8.js
  → 8 тестів: стіл на трьох, втеча, ПвЄ, стіл дня, ставка няву,
    амбасадори (обидва + чат + ачівки), розділення черг за збоєм, ліга ПвЄ + онлайн.
  → надійний раннер (піднімає сервер через child_process,
    щоб уникнути проблем з shell-бекграундом): стіл на трьох,
    втеча з вкладки, ПвЄ, стіл дня, ставка няву.
    сервер тестів завжди має BOT_FAST=1 (бот ходить швидко;
    у проді на Railway цієї змінної нема — бот людського темпу).

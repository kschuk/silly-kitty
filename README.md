сервер + вбудований клієнт в одному пакеті.
один деплой на railway — і за тією ж адресою вже грають.

─────────────────────────
ЩО ВСЕРЕДИНІ
─────────────────────────
server.js            — кімнати, швидка гра, ходи, няв-няв-няв,
                       рейтинг ело, форфейти, реванш
core.js              — чисті правила гри (те саме ядро, що в прототипі)
store.js             — сховище гравців (json-файл у data/)
public/index.html    — веб-клієнт: лобі, гра, рекорди
test_integration.js  — тест: двоє клієнтів грають 3 партії
package.json

─────────────────────────
ЛОКАЛЬНИЙ ЗАПУСК
─────────────────────────
npm install
npm start
→ http://localhost:3000
відкрий у двох вкладках (звичайна + інкогніто, щоб жетони
були різні) — і грай сам із собою для перевірки.

тест: npm install --include=dev && npm test
(сервер має бути запущений на порту 3111: PORT=3111 npm start)

─────────────────────────
ДЕПЛОЙ НА RAILWAY
─────────────────────────
шлях 1 · через github (рекомендую):
1. залий цю теку як репозиторій на github
2. railway.app → New Project → Deploy from GitHub repo
3. railway сам побачить package.json і запустить npm start
4. Settings → Networking → Generate Domain — це адреса гри

шлях 2 · через cli:
1. npm i -g @railway/cli && railway login
2. у цій теці: railway init → railway up
3. згенеруй домен так само

ВАЖЛИВО · збереження рекордів:
файлова система railway зникає при редеплої. щоб всесвітня
таблиця пережила оновлення:
Service → Settings → Volumes → Add Volume → mount path: /app/data
без volume рекорди житимуть до першого редеплою
(аркадний автомат, висмикнутий з розетки).

порт задається змінною PORT — railway робить це сам.

─────────────────────────
ЯК ПРАЦЮЄ АРКАДНА СИСТЕМА
─────────────────────────
• при першому вході пристрій генерує жетон (localStorage)
  і гравець обирає нік. жодних реєстрацій.
• рейтинг рахується на сервері під жетоном: ело, K=32,
  нульова сума. нічия = 0.5.
• технічна поразка: розрив понад 60 с або мовчання у свій хід
  понад 120 с (константи вгорі server.js).
• всесвітня таблиця: топ-50 за рейтингом, нік + очки + ігри.
  дублікати ніків дозволені — як на автоматах.
• очистив дані браузера = нова особистість. це не баг,
  це монетка в новий автомат.

⚙ ТОЧКИ НАЛАШТУВАННЯ
